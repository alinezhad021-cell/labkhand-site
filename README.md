# سایت لبخند — labkhandhandbake.ir

صفحه‌ی اصلی = دقیقاً منوی سه‌صفحه‌ای لبخند (کیک‌ها / کوکی‌ها و رول دارچین / کلوچه‌ها / دسرها)، با همه‌ی قیمت‌ها.
HTML/CSS خالص، بدون بیلد. ساختار تخت، بدون پوشه. فونت گرامافون (نسخه FaNum Clean) با نام gramophone.woff2 داخل خود سایت جاسازی شده و لوگوی هدر logo.png است.

وضعیت دامنه (چک‌شده ۲۱ اکتبر ۲۰۲۶): `labkhandhandbake.ir` در DNS هیچ رکورد و نیم‌سروری ندارد (از رجیستری .ir پاسخ NXDOMAIN می‌آید) — یعنی وصل‌کردن دامنه از صفر انجام می‌شود و چیزی سر راه نیست.

## قدم ۱ — سایت را روی Vercel بالا ببر

مسیر بدون ترمینال (پیشنهادی):
1. برو https://github.com/new — یه ریپوی جدید بساز، مثلاً `labkhand-site` — و همه‌ی فایل‌های این پوشه را آپلود کن (گزینه‌ی uploading an existing file).
2. برو https://vercel.com/new — با همون اکانت گیت‌هاب وارد شو — ریپوی `labkhand-site` را Import کن — Deploy.
   هیچ تنظیمی لازم نیست؛ Framework خودکار «Other» تشخیص داده می‌شود.
3. آخرش یه آدرس موقت می‌گیری مثل `labkhand-site.vercel.app` — اول مطمئن شو منو آنجا درست دیده می‌شود، بعد برو قدم ۲.

مسیر جایگزین (با ترمینال): داخل این پوشه `npm i -g vercel` و بعد `vercel --prod`.

## قدم ۲ — دامنه را به Vercel وصل کن

1. در Vercel: پروژه → **Settings → Domains → Add**
2. اول `labkhandhandbake.ir` را اضافه کن، بعد `www.labkhandhandbake.ir` را هم اضافه کن و بگذار www به دامنه‌ی اصلی ریدایرکت شود.
3. Vercel دو راه پیش پایت می‌گذارد — **راه ساده‌تر برای دامنه‌ی .ir همینی است که پایین می‌آید:**

### اتصال از ایرنیک (nic.ir) — مسیر قطعی برای این دامنه

دامنه مستقیم از ایرنیک گرفته شده. نکته‌ی کلیدی: **ایرنیک فقط نیم‌سرور قبول می‌کند** و جایی برای ثبت رکورد A/CNAME ندارد — پس تنها راه، سپردن نیم‌سرورها به Vercel است (رکورد دستی در کار نیست).

ترتیب مهم است — اول Vercel، بعد ایرنیک:

**الف) در Vercel** (بعد از قدم ۱ و اضافه‌کردن دامنه در قدم ۲):
صفحه‌ی دامنه باید بگوید نیم‌سرورها را به Vercel بده. مقادیر استاندارد Vercel:
- `ns1.vercel-dns.com`
- `ns2.vercel-dns.com`

**ب) در ایرنیک:**
1. وارد nic.ir شو → «دامنه‌های من» → روی `labkhandhandbake.ir` کلیک کن.
2. بخش «سامانه نام دامنه (DNS)» → دکمه‌ی «ویرایش سامانه نام دامنه».
   (اگر دکمه فعال نبود: شناسه‌ات باید «رابط فنی» دامنه باشد؛ در همان صفحه‌ی دامنه رابط‌ها را چک کن.)
3. نیم‌سرورها را دقیقاً این‌طور پر کن — ایرنیک برای هر نیم‌سرور، آی‌پی هم می‌خواهد:
   - کارگزار اول: نام `ns1.vercel-dns.com` — آی‌پی `198.51.44.13`
   - کارگزار دوم: نام `ns2.vercel-dns.com` — آی‌پی `198.51.45.13`
   - بقیه‌ی ردیف‌ها (سوم و چهارم) را خالی بگذار.
4. «اعمال تغییرات» را بزن.

**ج) صبر:** ایرنیک تغییرات نیم‌سرور را با کمی تأخیر در زون .ir اعمال می‌کند؛ مجموعاً چند ساعت تا ۲۴ ساعت. وقتی در Vercel جلوی دامنه تیک Valid Configuration آمد، اتصال کامل است.

## قدم ۳ — صبر و تأیید
- انتشار تغییرات DNS برای دامنه‌های .ir ممکن است از چند ساعت تا ۲۴ ساعت طول بکشد.
- وقتی در Vercel جلوی دامنه تیک **Valid Configuration** آمد و قفل SSL سبز شد، کار تمام است: سایت روی `https://labkhandhandbake.ir` زنده است.

## ویرایش قیمت‌ها
قیمت‌ها مستقیم در `index.html` نوشته شده‌اند — عدد را عوض کن، در گیت‌هاب آپلود/کامیت کن، Vercel خودکار نسخه‌ی جدید را منتشر می‌کند.
